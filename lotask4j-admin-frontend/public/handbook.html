异步慢任务服务

ASTS (Asynchronous Slow Task Service) 是一个高性能的异步任务调度平台，专注于处理耗时任务的后台执行、状态追踪和结果回调。

RESTful API 生产可用 OpenAPI 3.0 多语言 SDK

核心特性

分布式任务调度
实时进度追踪
多 Worker 负载均衡
Webhook 回调
任务取消支持
智能重试机制

快速开始

前提条件
确保后端服务已启动 (默认端口 9080)，并已完成 Worker 节点注册。
1
配置任务类型
在管理后台创建任务类型，定义超时时间、最大重试次数等参数
2
客户端提交任务
通过 Client API 提交任务，获取 TaskId 用于后续查询
3
Worker 抢接任务
Worker 通过 Poll 机制竞争获取待执行任务
4
执行并上报进度
Worker 执行任务，定期上报进度直至完成
5
接收结果回调
任务完成后自动触发 Webhook 回调通知客户端

客户端代码示例

Java 集成示例

AstsClient.java
package com.example.service;

import org.springframework.stereotype.Service;
import org.springframework.web.client.RestTemplate;
import org.springframework.http.*;
import java.util.Map;
import java.util.HashMap;

@Service
public class AstsClient {
    private final RestTemplate restTemplate;
    private final String astsBaseUrl = "http://localhost:9080/api/v1/client";

    /** 提交任务 */
    public String submitTask(String taskType, Map<String, Object> payload,
                             Integer priority, String callbackUrl) {
        Map<String, Object> request = new HashMap<>();
        request.put("type", taskType);
        request.put("payload", payload);
        request.put("priority", priority);
        request.put("callbackUrl", callbackUrl);

        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_JSON);
        HttpEntity<Map<String, Object>> entity = new HttpEntity<>(request, headers);
        ResponseEntity<Map> response = restTemplate.postForEntity(astsBaseUrl + "/tasks", entity, Map.class);
        Map<String, Object> body = response.getBody();
        if (body != null && (Integer) body.get("code") == 0) {
            Map<String, Object> data = (Map<String, Object>) body.get("data");
            return (String) data.get("id");
        }
        throw new RuntimeException("提交任务失败");
    }

    /** 查询任务状态 */
    public Map<String, Object> getTaskStatus(String id) {
        ResponseEntity<Map> response = restTemplate.getForEntity(astsBaseUrl + "/tasks/" + id, Map.class);
        Map<String, Object> body = response.getBody();
        if (body != null && (Integer) body.get("code") == 0) {
            return (Map<String, Object>) body.get("data");
        }
        throw new RuntimeException("查询任务失败");
    }

    /** 轮询等待任务完成 */
    public Map<String, Object> waitForTask(String id, long timeoutMs) throws InterruptedException {
        long startTime = System.currentTimeMillis();
        long delay = 1000;
        long maxDelay = 30000;
        while (true) {
            if (System.currentTimeMillis() - startTime > timeoutMs) {
                throw new RuntimeException("等待任务超时");
            }
            Map<String, Object> task = getTaskStatus(id);
            String status = (String) task.get("status");
            if ("SUCCESS".equals(status) || "FAILED".equals(status) || "CANCELLED".equals(status)) {
                return task;
            }
            Thread.sleep(delay);
            delay = Math.min((long)(delay * 1.5), maxDelay);
        }
    }
}

TypeScript 集成示例

asts-client.ts
import axios, { AxiosInstance } from 'axios';

export class AstsClient {
  private client: AxiosInstance;

  constructor(baseURL: string = 'http://localhost:9080/api/v1/client') {
    this.client = axios.create({ baseURL, headers: { 'Content-Type': 'application/json' } });
  }

  async submitTask(request: any): Promise<string> {
    const response = await this.client.post('/tasks', request);
    if (response.data.code === 0) return response.data.data.id;
    throw new Error(`提交任务失败: ${response.data.message}`);
  }

  async getTaskStatus(id: string): Promise<any> {
    const response = await this.client.get(`/tasks/${id}`);
    if (response.data.code === 0) return response.data.data;
    throw new Error(`查询任务失败: ${response.data.message}`);
  }

  async waitForTask(id: string, timeoutMs: number = 600000): Promise<any> {
    const startTime = Date.now();
    let delay = 1000;
    while (true) {
      if (Date.now() - startTime > timeoutMs) throw new Error('等待任务超时');
      const task = await this.getTaskStatus(id);
      if (['SUCCESS', 'FAILED', 'CANCELLED'].includes(task.status)) return task;
      await new Promise(r => setTimeout(r, delay));
      delay = Math.min(delay * 1.5, 30000);
    }
  }
}

Worker 使用指南

Worker（工作端）是分布式任务执行节点，负责 Poll 任务、执行业务逻辑、上报进度、检测取消信号和上报结果。

Worker 架构特点

无状态设计
Worker 不直接访问数据库，所有操作通过 HTTP API 与 ASTS 交互，易于水平扩展
Poll 机制
Worker 主动拉取任务，使用 SELECT FOR UPDATE SKIP LOCKED 避免竞争，Poll 即心跳
协作式取消
Worker 定期检测取消信号，检测到 CANCELLING 后停止业务逻辑并上报 CANCELLED

Worker 执行流程

Worker Poll 循环
步骤操作说明
1WorkerPOST /worker/tasks/poll 拉取任务
2APISELECT FOR UPDATE SKIP LOCKED + UPSERT worker_node
3API返回任务详情，状态设为 RUNNING
4Worker执行业务逻辑
5WorkerPOST /tasks/progress 上报进度
6WorkerGET /tasks/status 检测取消信号
7WorkerPOST /tasks/result 上报结果 SUCCESS

Worker 实现示例

1. ASTS Worker 客户端封装

AstsWorkerClient.java
@Component
public class AstsWorkerClient {
    private final RestTemplate restTemplate;
    private final String astsBaseUrl = "http://localhost:9080/api/v1/worker";

    /** Poll 任务 */
    public Map<String, Object> pollTask(String taskType, String strategy, String workerIp) {
        Map<String, Object> request = new HashMap<>();
        request.put("taskType", taskType);
        request.put("strategy", strategy);
        request.put("workerIp", workerIp);
        HttpEntity<Map<String, Object>> entity = new HttpEntity<>(request);
        ResponseEntity<Map> response = restTemplate.postForEntity(astsBaseUrl + "/tasks/poll", entity, Map.class);
        Map<String, Object> body = response.getBody();
        if (body != null && (Integer) body.get("code") == 0) {
            return (Map<String, Object>) body.get("data");
        }
        return null;
    }

    /** 检测取消信号 */
    public String getTaskStatus(String id) {
        ResponseEntity<Map> response = restTemplate.getForEntity(astsBaseUrl + "/tasks/" + id + "/status", Map.class);
        Map<String, Object> body = response.getBody();
        if (body != null && (Integer) body.get("code") == 0) {
            Map<String, Object> data = (Map<String, Object>) body.get("data");
            return (String) data.get("status");
        }
        return null;
    }

    /** 上报进度 */
    public void reportProgress(String id, int progress, String currentStep, String currentStepKey) {
        Map<String, Object> request = new HashMap<>();
        request.put("progress", progress);
        request.put("currentStep", currentStep);
        request.put("currentStepKey", currentStepKey);
        HttpEntity<Map<String, Object>> entity = new HttpEntity<>(request);
        restTemplate.postForEntity(astsBaseUrl + "/tasks/" + id + "/progress", entity, Map.class);
    }

    /** 上报结果 */
    public void reportResult(String id, String status, Map<String, Object> result, String errorMsg) {
        Map<String, Object> request = new HashMap<>();
        request.put("status", status);
        request.put("result", result);
        request.put("errorMsg", errorMsg);
        HttpEntity<Map<String, Object>> entity = new HttpEntity<>(request);
        restTemplate.postForEntity(astsBaseUrl + "/tasks/" + id + "/result", entity, Map.class);
    }
}

2. 任务执行器基类

TaskExecutor.java
public abstract class TaskExecutor {
    protected final AstsWorkerClient astsClient;

    public TaskExecutor(AstsWorkerClient astsClient) { this.astsClient = astsClient; }

    public void execute(Map<String, Object> task) {
        String id = (String) task.get("id");
        Map<String, Object> payload = (Map<String, Object>) task.get("payload");
        try {
            Map<String, Object> result = doExecute(id, payload);
            astsClient.reportResult(id, "SUCCESS", result, null);
        } catch (CancelledException e) {
            astsClient.reportResult(id, "CANCELLED", null, "用户取消任务");
        } catch (Exception e) {
            astsClient.reportResult(id, "FAILED", null, e.getMessage());
        }
    }

    protected abstract Map<String, Object> doExecute(String id, Map<String, Object> payload) throws Exception;

    protected void checkCancellation(String id) throws CancelledException {
        String status = astsClient.getTaskStatus(id);
        if ("CANCELLING".equals(status)) throw new CancelledException();
    }

    protected void reportProgress(String id, int progress, String currentStep, String currentStepKey) {
        astsClient.reportProgress(id, progress, currentStep, currentStepKey);
    }

    public static class CancelledException extends Exception {}
}

DataExportExecutor.java
@Component
public class DataExportExecutor extends TaskExecutor {
    public DataExportExecutor(AstsWorkerClient astsClient) { super(astsClient); }

    @Override
    protected Map<String, Object> doExecute(String id, Map<String, Object> payload) throws Exception {
        // 步骤 1: 初始化
        reportProgress(id, 5, "初始化", "init");
        checkCancellation(id);
        Thread.sleep(500);

        // 步骤 2: 数据查询
        reportProgress(id, 20, "数据查询", "querying");
        checkCancellation(id);

        // 模拟查询大量数据
        int totalRows = 100000;
        for (int i = 0; i < 10; i++) {
            Thread.sleep(2000);
            checkCancellation(id);
            int progress = 20 + ((i + 1) * 60 / 10);
            reportProgress(id, progress, "数据查询", "querying");
        }

        // 步骤 3: 文件写入
        reportProgress(id, 85, "文件写入", "writing");
        checkCancellation(id);
        Thread.sleep(3000);

        // 构造结果
        Map<String, Object> result = new HashMap<>();
        result.put("fileUrl", "https://oss.example.com/export_" + id + ".xlsx");
        result.put("rows", totalRows);
        return result;
    }
}

4. Worker 主循环

WorkerRunner.java
@Component
public class WorkerRunner implements CommandLineRunner {
    private final AstsWorkerClient astsClient;
    private final DataExportExecutor dataExportExecutor;

    @Override
    public void run(String... args) throws Exception {
        String workerIp = InetAddress.getLocalHost().getHostAddress();
        Map<String, TaskExecutor> executors = new HashMap<>();
        executors.put("data_export", dataExportExecutor);

        while (true) {
            try {
                Map<String, Object> task = astsClient.pollTask("data_export", "PRIORITY", workerIp);
                if (task != null) {
                    String taskType = (String) task.get("type");
                    TaskExecutor executor = executors.get(taskType);
                    if (executor != null) executor.execute(task);
                } else {
                    Thread.sleep(5000);
                }
            } catch (Exception e) {
                Thread.sleep(5000);
            }
        }
    }
}

private volatile boolean running = true;

@Override
public void run(String... args) throws Exception {
    Runtime.getRuntime().addShutdownHook(new Thread(this::shutdown));

}

private void shutdown() {
    running = false;
    executorService.shutdown();
    if (!executorService.awaitTermination(60, TimeUnit.SECONDS)) {

}

任务状态机

PENDING → RUNNING → SUCCESS

↓ FAILED ← CANCELLED
状态说明触发条件
PENDING等待处理任务提交后进入此状态
RUNNING执行中Worker 抢接任务后开始执行
SUCCESS执行成功Worker 上报完成且 exitCode=0
FAILED执行失败Worker 上报完成且 exitCode≠0
CANCELLED已取消客户端发起取消请求

常见问题

Q: 任务执行超时怎么办？

在任务类型配置中设置超时时间 (default-timeout)，Worker 需要在超时前完成任务或上报进度。系统会自动标记超时任务为失败。

Q: 如何保证任务不丢失？

Worker 异常退出时，任务会在心跳超时后被重新放回队列供其他 Worker 抢接。建议 Worker 实现优雅退出，监听取消信号。

Q: 支持批量任务吗？

当前版本需要逐个提交任务。批量功能已在规划中。

Q: 取消任务后多久生效？

取消是协作式的。取消请求会立即将任务状态更新为 CANCELLING，Worker 在下次检测取消信号时会停止执行。停止时间取决于 Worker 的检测频率（建议 5-10 秒）。

Q: 如何处理大量并发任务？

通过 Worker 线程池实现并发控制。可以在任务类型配置中设置 max_concurrency 限制单个任务类型的并发数。
