# 错误码

所有业务接口 HTTP 200 + 信封返回，业务成败以 `code` 判定（路由层 4xx/5xx 例外，见[公共约定](api-conventions.md)）。

## 通用错误

| code | 含义 | 排查建议 |
|------|------|----------|
| `0` | 成功 | — |
| `401` | 认证失败（认证端点凭据错误/租户停用/宽限期已过） | 核对 client_id/client_secret；确认租户 `ACTIVE`；检查密钥是否已轮换 |
| `10001` | 系统繁忙（服务端缺陷，HTTP 500） | 携 `trace_id` 联系平台方 |
| `10005` | 中间件错误 | 服务端部署问题（缺编译参数），联系平台方 |
| `10102` | 参数格式错误 | 检查路径/查询参数类型（如把非数字传给数字参数） |
| `10104` | HTTP 方法不支持（405） | 核对请求方法 |
| `10105` | 媒体类型不支持（415） | POST/PUT 请带 `Content-Type: application/json` |
| `10106` | 业务规则校验失败 | 看 message：常见为 ID 格式非法、唯一键冲突、组件不匹配 |
| `10400` | 资源不存在（404） | 核对路径 |
| `10500` | 请求过于频繁（限流） | 指数退避重试；确认调用频次是否超出约定 |

## 任务类

| code | 含义 | 排查建议 |
|------|------|----------|
| `20001` | 任务提交失败 | 看 message 中的底层原因；偶发可带幂等键重试 |
| `20006` | 任务队列已满 | 背压生效；降低提交速率或联系运营调大该类型的队列上限 |
| `20100` | 任务不存在 | 核对 ID；**跨租户访问也返回此码**（不泄露存在性） |
| `20101` | 未知的任务类型 | 联系运营配置类型，或核对 `type` 拼写 |
| `20102` | 任务类型已禁用 | 联系运营启用 |
| `20401` | 任务状态不允许取消 | 仅 `PENDING`/`RUNNING` 可取消 |
| `20409` | 任务状态已变更 | 并发冲突：重新查询最新状态；Worker 侧应停止执行 |

## 认证与租户类

| code | 含义 | 排查建议 |
|------|------|----------|
| `20103` | 缺少必要的认证参数 | 核对 grant_type / client_id / client_secret 是否齐全 |
| `20104` | 不支持的 grant_type | 仅支持 `client_credentials` |
| `20105` | client_id 或 client_secret 无效 | 凭据错误；确认是否用了重置前的旧钥且宽限期已过 |
| `20106` | 应用（租户）不存在 | 核对租户 ID；租户可能已被删除 |
| `20107` | 应用状态非法 | 状态仅支持 `ACTIVE` / `INACTIVE`（映射 `SUSPEND`） |

## Worker 上报类

| code | 含义 | 排查建议 |
|------|------|----------|
| `20409` | 状态机冲突（progress/result 上报被拒） | 租约过期被重派 / 已发起取消 / version 落后。停止执行，重新轮询 |
| `20100` | 上报的任务不存在或跨租户 | 核对任务 ID 与租户凭据 |

## 排障通用流程

1. 拿到 `trace_id`（响应信封携带），先查服务端日志；
2. 对照上表自查入参；
3. 任务类问题到管理台看**执行事件时间线**（`GET /api/v1/admin/tasks/{id}/events`）；
4. 仍无法解决时向平台方提供：trace_id、请求报文、时间点。
